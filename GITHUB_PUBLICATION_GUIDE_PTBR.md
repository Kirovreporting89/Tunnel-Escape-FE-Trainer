# Como publicar o Tunnel Escape FE Trainer V6.6 no GitHub

1. Entre em https://github.com/new e crie um repositório público chamado `Tunnel-Escape-FE-Trainer`.
2. Selecione `Add a README file` apenas se for criar manualmente o README depois. Caso queira enviar todos os arquivos do pacote de código-fonte, pode criar o repositório vazio.
3. Dentro do repositório, escolha `Add file` > `Upload files`, envie os arquivos e pastas do pacote `GITHUB_FONTE_PRONTO.zip` (primeiro EXTRAIA o ZIP e depois envie os arquivos extraídos). Confirme em `Commit changes`.
4. Confira que README.md aparece na página inicial. Pode editar a descrição do repositório com o texto em inglês fornecido.
5. Na página inicial clique `Releases` > `Draft a new release`.
6. Em `Choose a tag`, crie `v6.6`, com título `Tunnel Escape FE Trainer v6.6`.
7. Cole o conteúdo do `RELEASE_NOTES_v6.6.md` na descrição da release.
8. Anexe o EXE `TUNNEL_ESCAPE_FE_TRAINER_V6_6_SEM_F8.exe` e/ou `TUNNEL_ESCAPE_FE_TRAINER_V6_6_SEM_F8_WINDOWS.zip` na caixa de arquivos binários.
9. Clique `Publish release`.
10. Teste em janela anônima: o README deve ficar visível e os downloads devem abrir em Releases.

IMPORTANTE: não envie o jogo nem arquivos comerciais protegidos por direitos autorais sem permissão. Revise a arte, o ícone e os direitos sobre os assets antes de deixar o repositório público. Se quiser distribuir o código sob licença open source, escolha uma licença apropriada para os arquivos de sua autoria.

O README e as notas de versão estão em inglês. O arquivo do executável fica em `Releases`, e o código e documentação no repositório.
