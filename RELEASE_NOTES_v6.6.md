# Tunnel Escape FE Trainer v6.6 — External Panel Edition

A free, fan-made trainer for **Tunnel Escape: Fates Entwined** (Windows 10/11, 64-bit, offline/single player).

## What's new

- Removed the old in-game **F8** cheat panel. Use the separate desktop trainer instead.
- Preserved all **9 cheats** and their adjustable multipliers.
- Kept the HD icon set, animated interface, and **JOGAR / Play** button.
- Preserved the game's local bridge, status display, and backup/restore feature.

## Installation

1. Download the `.exe` attached below, or download and extract the Windows `.zip`.
2. Close the game and run the trainer.
3. Click **LOCALIZAR JOGO** and select the game folder (or its `www` folder).
4. Click **INSTALAR PONTE** with the game closed, even if you used an older trainer before.
5. Click **JOGAR** to launch the game and control cheats from the external window.

> **Important:** A new trainer EXE does not automatically update your installed game plugin. Use **INSTALAR PONTE** once to remove the old F8 menu.
